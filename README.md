# Student Survival - Academic Boss Rush

Action game where each university exam becomes a unique gameplay challenge with different mechanics. The game map is based on the real floor plan of IFRS Campus Farroupilha. Built with Godot Engine for the Software Engineering course at IFRS (2019).

live game: https://auguro.itch.io/student-survival (may be buggy)

## 🎮 Game Concept
Play as a student navigating the actual IFRS campus layout, facing end-of-semester exams where each subject transforms into a distinct game genre:

### 📚 Exam Challenges

**Mathematics - DOOM-Style FPS**
- Survive waves of enemies in first-person shooter mode
- Kill all enemies to pass the exam
- **Controls:** WASD (move), Left Mouse (shoot), E (change weapon)

**Portuguese - Bullet Hell Typing**
- Boss fight with projectile dodging mechanics
- Type Portuguese words displayed on screen while avoiding bullets
- **Controls:** Arrow keys (move), Keyboard letters (type words)

**Biology - Tower Defense** *(Work in Progress)*
- Play as red blood cells defending against bacteria
- Tower defense mechanics in biological context

## 🏫 Unique Feature
The game world is modeled after the real floor plan of IFRS Campus Farroupilha, creating an authentic campus experience combined with arcade gameplay.

## 🛠️ Technologies
- **Godot Engine 3.x** - Game engine
- **GDScript** - Game logic and mechanics
- **Custom Assets** - Original sprites and textures

## 🎯 Concepts Demonstrated
- Multi-genre game design in single project
- Scene management and state switching
- Different control schemes per game mode
- Boss fight mechanics
- Typing game implementation
- FPS mechanics in 2D engine

## 🎓 Academic Context
Developed in 2019 for the Software Engineering course at IFRS as a creative project combining game development with academic themes. Demonstrates ability to implement multiple gameplay systems within a unified game structure.

## ⚠️ Note
Biology mode is currently non-functional and marked as work-in-progress. Mathematics and Portuguese modes are fully playable.
